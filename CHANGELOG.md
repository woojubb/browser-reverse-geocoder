# Changelog

## [1.0.1] - 2024-09-01

### Changed
- Updated readme with usage examples and GeoJSON format documentation

## [1.0.0] - 2024-09-01

### Added
- Initial release
- `BrowserReverseGeocoder` class with `init()` and `reverseGeocode()` methods
- RBush spatial indexing for fast lookups
- Turf.js `booleanPointInPolygon` for accurate point-in-polygon detection
- Support for custom GeoJSON datasets
- ES module and UMD build outputs via Vite
